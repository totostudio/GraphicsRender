## 🚀 Quick Start
Every episode directory contains a standalone `index.html` and modular GLSL files in `shaders/`:
1. **Zero Dependencies**: No `npm install`, no build tools, no webpack.
2. **Instant Run**: Simply double-click `index.html` in any modern web browser with WebGL2 support.
3. **Debug Controls**: Press keys `1` ~ `5` in each demo to switch between different rendering buffers, G-Buffers, heatmaps, and diagnostic views.
